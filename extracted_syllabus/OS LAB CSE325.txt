CSE325
:
OPERATING SYSTEMS LABORATORY
Course Outcomes:
CO1 :: 
Understand Linux command-line tools and system utilities to manage users, groups, 
packages, and files in a Linux environment.
CO2 :: 
Apply automation scripts using Bash shell scripting using variables, conditionals, loops, 
arrays, functions
CO3 :: 
Use low-level file and directory operations using OS system calls
CO4 :: 
Contrast process creation and management using fork and exec.
CO5 :: 
Demonstrate multithreading and synchronization mechanisms using POSIX threads, 
mutexes, and semaphores to resolve race conditions.
CO6 :: 
Apply inter-process communication mechanisms using pipes, shared memory
Through this course students should be able to
Linux Ecosystem & Infrastructure
Linux Distributions & Families
Command Line Fundamentals
User & Group Management
Package Management
Shell Scripting
Script creation, execution, and permissions
Environment and user-defined variables.
Arithmetic operations using expr and bc
Input/Output redirection and pipes.
Conditional statements and menu-driven programs
Looping constructs: for, while, until.
Indexed and associative arrays
User-defined functions and parameter passing
File system management
File system calls: open, read, write, close, lseek
Process Management & Signals
Process creation using fork()
Program execution using exec()
Orphan and Zombie processes
Process synchronization using wait() and signals.
Multithreading & Synchronization
POSIX thread creation and termination
Race conditions and critical sections
Mutex locks and semaphores
Inter-Process Communication (IPC)
Pipes and Named FIFOs

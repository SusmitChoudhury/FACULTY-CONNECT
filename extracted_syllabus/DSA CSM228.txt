CSM228
:
DATA STRUCTURES
Course Outcomes:
CO1 :: 
describe the process to find efficiency of algorithms using asymptotic notations
CO2 :: 
illustrate the importance of Queue in context of problems solving
CO3 :: 
differentiate the HashTable and HashMap in context of writing efficient program
Unit I
Introduction
 : 
Basic Data Structures, Basic Concepts and Notations, Complexity analysis: time space 
and trade of, Omega Notation, Theta Notation, Big O notation
Stacks
 : 
Introduction to Stacks, Implementing a stack, Parenthesis matching problem using Stacks, 
Industry demonstration: File versioning system
Unit II
Queues
 : 
Introduction to Queues, implement a stack using one queue, implement a stack using two 
queues, Ticket booking system using Queues, Palindromic string problem, Duplicate parenthesis 
problem, Reversing a stack problem, Kth largest element problem
Unit III
HashTables
 : 
Design and performance analysis of hash tables, Hash functions and hashing, Collision 
in hash tables, how to check if a given hash function is good or bad, Implementation of a dictionary 
(phone book) using a hash table
HashMaps
 : 
Introduction to the HashMaps, Find Symmetric Pairs problem, Find Asymmetric Pairs 
problem, First Unique Character problem
Unit IV
HashSets
 : 
Introduction to the HashSets, Array of Contiguous Integers problem, Pair with a Given 
Sum problem, Itinerary From all Tickets problem, Match Locks and Keys problem
Binary Trees
 : 
Linear vs non-Linear data structures, Types & Representation of binary trees, Trees & 
Binary Trees, Properties, Tree Traversal: DFS & BFS, Title problem: Runway Reservation, Mirroring a 
tree problem, Spiral order traversal of a tree
Binary Search Trees
 : 
Introduction to the Binary Search Trees, Searching, Insertion & Deletion in a 
BST, Lowest common ancestor problem, Balanced BSTs, Solution of the Title Problem
Unit V
Priority Queues
 : 
Introduction to the Priority queues with example, Priority queues ADT, 
Implementation of priority queues using LinkedList and ArrayList
Heaps
 : 
Introduction to the Heaps, Basic operations performed on heaps, Sorting, Merge k sorted 
linked list problem, Median of stream of integers problem
Unit VI
Graphs and Graph Algorithms
 : 
Adjacency matrix, Application of graphs in real life, Depth-First 
Search, Breadth-First Search, Adjacency list, Edge list, Dijkstra
s algorithm
CO4 :: 
identify the appropriateness of HashSet and tree in problem solving
CO5 :: 
analyze the effectiveness of Priority queue and Heap Data Structures
CO6 :: 
use of Graph and various techniques in real world problem solving
